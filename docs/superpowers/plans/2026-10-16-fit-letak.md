# Fit nákupní leták Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Osobní PWA, která z denně stahovaných akčních letáků šesti českých řetězců dělá prohledávatelný leták s Fit režimem, generuje cenově optimalizované fit jídelníčky a skládá z nich nákupní seznam.

**Architecture:** npm workspaces se třemi balíčky: `shared/` (typy a čistá logika), `scraper/` (Node CLI, který píše `app/public/data/offers.json`) a `app/` (Vite + React PWA, čte statické JSON soubory). Jediné rozhraní mezi scraperem a aplikací jsou JSON soubory. Žádný server.

**Tech Stack:** TypeScript, Node 20+, npm workspaces, Vitest, Cheerio, tsx, Vite + React, vite-plugin-pwa, MiniSearch, idb-keyval, GitHub Actions + GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-16-fit-letak-design.md`

## Global Constraints

- Obchody: `lidl`, `albert`, `billa`, `kaufland`, `penny`, `tesco`.
- UI v češtině, měna Kč, desetinná čárka při zobrazení.
- Scraper běží 1× denně; při selhání nebo prázdném výsledku zůstává poslední úspěšný `offers.json`.
- Nutriční hodnoty jsou na 100 g; každý záznam nese `source` a `confidence`.
- Generátor: kcal v rozsahu ±5 % cíle, bílkoviny ≥ cíl, tuk ≤ limit, minimální cena, střídání receptů; chybějící cena = poslední známá, označeno jako odhad.
- ~30–40 fit receptů v `recipes.json`, suroviny jsou obecné (ne konkrétní produkty).
- Nabídka po `validTo` se skryje; UI ukazuje stáří dat.
- Produkt bez nutrice: ve Fit režimu skrytý, v běžném zobrazení s označením „bez maker“.
- Hledání: MiniSearch, bez ohledu na diakritiku a toleruje překlepy. Seznam v IndexedDB, appka funguje offline.
- Mimo rozsah: účty, backend, historie cen, nativní appka, LLM recepty.
- Kapalina se pro účely `pricePerKg` bere s hustotou 1 (1 l = 1 kg).

## Review Focus

1. Množství, které nejde zparsovat („2+1 zdarma“, „cca 1 kg“, prázdné, „10 ks“): nesmí spadnout, nabídka zůstane vyhledatelná, jen bez `pricePerKg`.
2. Dělení nulou: produkt s `protein = 0` nesmí dát `Infinity`/`NaN` v „Kč za 30 g bílkovin“ (výsledek `undefined`, řazení ho dá na konec).
3. Vyhledávání bez diakritiky a s překlepem („kureci“, „tvarog“) najde „Kuřecí“, „Tvaroh“.
4. Scraper vrátí 0 nabídek nebo výrazně méně než posledně (web se změnil): `offers.json` se nepřepíše a CLI skončí chybou.
5. Nesplnitelné cíle jídelníčku (6000 kcal, všechny suroviny vyloučené, rozpočet 1 Kč): generátor vrátí `satisfied: false` s důvodem, nepadne ani nezacyklí se.
6. Aplikace offline / `offers.json` se nenačte: použije se cache, nebo se ukáže srozumitelná chyba místo prázdné stránky.
